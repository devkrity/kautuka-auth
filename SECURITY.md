# Security Policy

## Supported versions

Security fixes are provided for the latest code on the `main` branch. There are
no published releases yet.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub private
vulnerability reporting, or email [security@devkrity.com](mailto:security@devkrity.com).
Include the affected commit or version, the impact, and clear reproduction
steps. Avoid opening a public issue or pull request for an unpatched
vulnerability.

We will acknowledge reports as soon as practical, investigate them, and
coordinate a fix and disclosure timeline with the reporter. Please allow time
for a fix to be prepared before sharing vulnerability details publicly.
